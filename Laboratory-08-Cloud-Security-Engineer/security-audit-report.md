# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and systems only the permissions they need to perform their assigned tasks. In cloud environments, this helps protect accounts and resources by preventing unnecessary access to sensitive information and services.

## 2. Attack Surface

An attack surface refers to all the possible points where an attacker could try to access or exploit a virtual machine. These may include open network ports, running services, applications, and user accounts. Reducing unnecessary access points helps make the server more secure.

## 3. Default Deny Policy

A Default Deny Policy means blocking all incoming network traffic unless it is specifically allowed by a firewall rule. This is safer because only trusted and necessary connections are permitted, instead of trying to identify and block every possible attacker individually.
