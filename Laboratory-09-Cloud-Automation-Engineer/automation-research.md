# Automation Research

## 1. Bash Script

A Bash script is a text file that contains a series of commands written for the Bash shell to execute automatically. The `#!/bin/bash` line, also known as the shebang, tells the operating system to use the Bash interpreter when running the script.

## 2. Variables

Variables are used to store information, such as directory paths, so programmers do not have to repeatedly type the same values in their commands. For example, `$BACKUP_DIR` stores the location of the backup folder, making the script easier to read, maintain, and modify.

## 3. Cron Job

A cron job is a scheduled task in Linux that automatically executes commands or scripts at specified times and dates. It is essential for cloud operations because it allows repetitive administrative tasks, such as backups, to run automatically without requiring someone to execute them manually.
