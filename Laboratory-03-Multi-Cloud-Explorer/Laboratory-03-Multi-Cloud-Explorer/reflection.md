# Mission 3 Reflection

## Become a Multi-Cloud Explorer

Completing Mission 3 helped me understand the differences and similarities between Amazon Web Services, Microsoft Azure, and Google Cloud Platform. Among the three platforms, Google Cloud impressed me the most because of its strong capabilities in Artificial Intelligence, Machine Learning, data analytics, and Kubernetes. These technologies are important for modern applications and show how cloud computing can support advanced workloads.

AWS, Azure, and GCP have many similarities because they all provide fundamental cloud computing services. All three platforms offer virtual machines, object storage, networking, identity management, databases, and Kubernetes services. They also provide scalable infrastructure that allows organizations to increase or decrease resources depending on their requirements.

Business requirements have an important influence on cloud platform selection. A company should not select a provider simply because it is popular. Instead, it should consider factors such as budget, existing infrastructure, required services, scalability, security, performance, and technical requirements. For example, Azure is a strong choice for organizations that already use Microsoft technologies, while GCP can be a strong option for AI and Kubernetes workloads.

Acting as a Cloud Solutions Consultant taught me that cloud decisions should be based on the actual needs of the client. Different organizations can require different solutions, so understanding the business problem is important before recommending a cloud provider.

My GitHub Cloud Computing Portfolio also improved after completing this mission. I added organized research documents, comparison tables, recommendations, Linux investigation results, screenshots, and a reflection. This made my portfolio more structured and helped me practice documenting technical information using Markdown.

Overall, this activity improved my understanding of multi-cloud computing and showed me how cloud technologies can be selected based on real-world business requirements.
