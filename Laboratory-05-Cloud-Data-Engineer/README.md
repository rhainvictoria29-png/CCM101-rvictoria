

# Laboratory 05 – The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I explored cloud storage and deployed an S3-compatible object storage server using MinIO and Docker. I created a bucket named `client-photos` and uploaded a sample file through the MinIO Web Console.

## Objectives

- Differentiate between Block Storage, File Storage, and Object Storage.
- Deploy MinIO using Docker.
- Access a cloud service through port forwarding.
- Create an object storage bucket.
- Upload a sample object to the bucket.
- Document the deployment using Markdown.
- Maintain an organized GitHub Cloud Computing Portfolio.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- Web browser
- GitHub
- Markdown

## Skills Learned

- Understanding the differences between cloud storage types.
- Running and checking Docker containers.
- Configuring container ports and environment variables.
- Accessing a web-based cloud management console.
- Creating buckets and uploading objects.
- Writing technical documentation in Markdown.
- Organizing laboratory evidence in GitHub.
