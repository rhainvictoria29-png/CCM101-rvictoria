# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to the basic environment and responsibilities of a cloud engineer. I used the KillerCoda Playground to access a cloud-based Linux environment and practiced working with Linux, files, directories, and GitHub.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Create and organize files and directories.
- Create a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

1. Accessed the Ubuntu Linux environment using KillerCoda.
2. Explored the Linux terminal.
3. Created a new Linux user and logged into the account.
4. Checked the username, working directory, and hostname.
5. Gathered information about the Linux distribution, kernel, CPU, memory, and disk space.
6. Created the required folder and file structure.
7. Created Markdown files for documentation.
8. Created a GitHub repository for the Cloud Computing portfolio.
9. Organized the laboratory files and screenshots in the repository.

## Linux Commands Used

Some of the Linux commands used during the activity include:

- `whoami` – displays the current username.
- `pwd` – displays the current working directory.
- `hostname` – displays the system hostname.
- `uname` – displays system and kernel information.
- `ls` – lists files and directories.
- `cd` – changes the current directory.
- `mkdir` – creates a new directory.
- `touch` – creates a new file.
- `cat` – displays file contents.
- `free` – displays memory information.
- `df` – displays available disk space.
