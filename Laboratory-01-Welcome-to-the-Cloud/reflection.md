# Reflection

This laboratory activity helped me understand the basic environment used by cloud engineers. I learned how to access a Linux system through KillerCoda, navigate the terminal, create users, and gather basic system information.

I also learned how to organize files and directories using Linux commands and document my work using Markdown. Creating a GitHub repository also showed me how important version control and proper documentation are when working on technical projects.

Overall, this activity gave me a good introduction to Linux, cloud environments, and GitHub. It also helped me understand the importance of keeping technical work organized and properly documented.
