# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on investigating the components of cloud infrastructure and understanding how compute, storage, networking, and identity services work together.

The activity uses the KillerCoda Playground and Linux tools to investigate a cloud-based Linux environment. The findings are documented using Markdown and organized as part of the GitHub Cloud Computing Portfolio.

## Objectives

- Explain the major components of cloud infrastructure.
- Investigate hardware and software resources available in a Linux environment.
- Differentiate compute, storage, networking, and identity resources.
- Understand the relationship between cloud infrastructure components.
- Create professional technical documentation using Markdown.
- Continue building a structured GitHub Cloud Computing Portfolio.

## Cloud Infrastructure Components

The main cloud infrastructure components investigated in this laboratory are:

- Compute Resources
- Storage Resources
- Networking Resources
- Operating System
- Identity and Access Management (IAM)

These components work together to provide the resources and services needed to operate cloud-based systems.
