# Cloud Provider Comparison

## Comparison of Core Infrastructure Services

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| Identity and Access Management (IAM) | AWS Identity and Access Management (IAM) | Microsoft Entra ID / Azure RBAC | Cloud Identity and Access Management (IAM) |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is widely known for offering a broad range of cloud services across computing, storage, networking, databases, security, analytics, and other areas. Its large selection of services allows organizations to build different types of cloud-based systems.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

Microsoft Azure would be a suitable choice for an organization that primarily uses Microsoft products. Azure provides strong integration with Microsoft's ecosystem, including Windows Server, Microsoft Entra ID, and other Microsoft services.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for its capabilities in Artificial Intelligence and Machine Learning. Google Cloud also provides Google Kubernetes Engine (GKE), which is a managed Kubernetes service.

### 4. What similarities did you observe among the three cloud providers?

All three cloud providers offer similar core infrastructure services, including compute, storage, networking, and identity and access management. They provide scalable cloud resources that organizations can use without maintaining all of the physical infrastructure themselves.
